## What I'm building

**[Tellability](https://goutham-dechineni.vercel.app/work/tellability)**, live at [tellability.com](https://tellability.com). An AI hiring platform I designed and built solo. Job seekers build their profile in a chat with an LLM agent; recruiters get candidates ranked by vector search, a structured score and a budgeted LLM review. In an early sample, Gemini context caching served 87.5% of prompt tokens from cache. The code is private; the write-up shows the architecture.
